
# Arena-de-estudo
Plataforma interativa de aprendizagem que reúne quizzes e jogos educativos sobre tecnologia. Permite explorar diferentes temas, testar conhecimentos e desenvolver habilidades de forma dinâmica, prática e divertida.




```bash
cp .env.example .env
touch database/database.sqlite
composer install
php artisan key:generate
php artisan migrate --seed
npm install
npm run build
composer run dev
```

Acesse:

```text
http://localhost:8000
```
